# Homecare — Chennai home services

| Folder | What |
| --- | --- |
| `website/` | Next.js marketing site (deploy this) |
| `design-system/` | Shared design tokens (Node build script → `dist/` + `website/src/styles/tokens.css`) |
| `mobile-app/` | React Native customer & professional apps (not started) |

## Deploy (Vercel)

Import the repo and set **Root Directory = `website`**. Framework preset: Next.js. See `website/README.md` and `website/.env.example` for environment variables (store URLs, analytics).
